# Guide RH — Demandes externes

Vous êtes la **porte d'entrée unique** de toutes les demandes venant de l'extérieur
(candidatures, stages, réclamations, sponsoring…). Vous seul pouvez les enregistrer
et envoyer la réponse officielle.

```text
Recevoir la demande → Créer le dossier → Ajouter les documents → Choisir l'urgence
→ Transmettre → Suivre la réponse → Répondre officiellement → Archiver
```

## 1. Recevoir la demande

La demande arrive par courrier, e-mail, téléphone ou dépôt au bureau. Rassemblez :
nom du demandeur, organisme éventuel, téléphone, e-mail, objet, date de réception, et les pièces
(scannez les documents papier en PDF).

## 2. Créer le dossier

Tableau de bord → **Nouvelle demande externe** (ou menu *RH → Nouvelle demande externe*).

| Champ | Conseil |
|---|---|
| Nom du demandeur / Organisme | Tels qu'ils figurent sur le courrier |
| Téléphone / E-mail | Pour la réponse officielle |
| Type | Stage, emploi, information, administrative, sponsoring, intervention, réclamation, autre |
| Date de réception | La date où la demande est **arrivée** (pas la date de saisie) |
| Canal | E-mail, courrier, téléphone, dépôt physique, autre |
| Objet / Description | Court et explicite (ex. « Demande de stage — master gestion ») |

À l'enregistrement, le numéro **DOS-AAAA-NNNNNN** est attribué automatiquement.

## 3. Ajouter les documents

Champ *Pièces jointes* : plusieurs fichiers possibles (PDF, Word, Excel, images, 20 Mo maximum
chacun par défaut). Exemple : CV et lettre de motivation. Vous pourrez en ajouter plus tard depuis le dossier.

## 4. Choisir l'urgence

| Urgence | Délai de réponse |
|---|---|
| Très urgent | 24 heures |
| Urgent | 3 jours calendaires |
| Normal | 7 jours calendaires |

La **date d'échéance est calculée automatiquement** (date de réception + délai) et affichée avant
l'enregistrement.

## 5. Transmettre

Section *Transmission* : choisissez un **département**, puis cochez le **responsable** (proposé en
premier) ou l'utilisateur concerné. Vous pouvez choisir **plusieurs personnes**, y compris dans
plusieurs départements. Cliquez **Enregistrer et transmettre** : chaque destinataire reçoit une notification 🔔.

## 6. Suivre la réponse

- Menu **Demandes externes** : tous les dossiers, avec recherche (numéro, demandeur, organisme) et filtre par statut.
- Quand un responsable rend sa décision (**positive ou négative**, avec justification et recommandation),
  vous recevez une notification et le dossier affiche le bloc **Suivi RH**.
- Si plusieurs responsables ne sont pas d'accord, **toutes les décisions restent visibles** : c'est à vous
  de décider de la réponse officielle.
- Si un délai est dépassé, vous êtes alerté automatiquement ; vous pouvez aussi cliquer **Relancer**
  sur la ligne du destinataire.

## 7. Répondre officiellement

Dans le dossier, bloc **Suivi RH → Enregistrer la réponse officielle** (possible dès qu'au moins une
décision est arrivée) :

- texte de la réponse envoyée au demandeur ;
- canal de réponse (e-mail, courrier, téléphone…) ;
- date d'envoi ;
- document éventuel (lettre signée).

Le dossier passe au statut **Répondu** et les responsables sont informés.

## 8. Archiver

Bouton **Archiver le dossier** : le dossier et tous ses traitements sont archivés. Rien n'est supprimé :
documents, réponses et historique restent consultables.

## Historique

En bas du dossier : **Historique complet** (qui, quand, quoi, ancienne → nouvelle valeur), exportable en
**PDF** ou **Word**.
