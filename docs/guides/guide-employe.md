# Guide Employé

## Connexion

Adresse interne (ex. `http://correspondance.local`), puis **nom d'utilisateur** et **mot de passe**
remis par l'administrateur. À la première connexion, vous devez choisir un nouveau mot de passe
(8 caractères minimum, avec une majuscule, une minuscule et un chiffre). Mot de passe oublié :
demandez à l'administrateur de le réinitialiser.

En haut à droite : 🔔 notifications, 🌙 mode clair/sombre, votre profil (photo, téléphone, e-mail
interne, changement de mot de passe, **Déconnexion**).

## Nouvelle demande

Tableau de bord → **Nouvelle demande** :

1. **Objet**, **type**, **urgence** (propose une date) et **date d'échéance** ;
2. **Destinataire(s)** : choisissez un **département**, puis cochez une ou plusieurs **personnes**
   (vous pouvez en ajouter de plusieurs départements) ;
3. **Description** et **pièces jointes** (PDF, Word, Excel, images) ;
4. **Envoyer la demande** : un numéro DOS-AAAA-NNNNNN est attribué, chaque destinataire est notifié.

Vous ne connaissez pas le bon destinataire ? Menu **Départements** : liste des collègues par département,
avec leur fonction.

## Suivi

- **Mes dossiers** : onglets *Reçus, Envoyés, Archivés, Tous*.
- Chaque destinataire a son propre statut : **Reçu → En cours → Répondu → Archivé**.
- L'échéance s'affiche en clair : « Échéance dans 3 jours », « Échéance demain », « Délai dépassé de 2 jours ».
- **Relancer** un destinataire qui n'a pas répondu : bouton sur sa ligne dans le dossier.
- **Modifier** votre dossier (objet, description, échéance) tant qu'il n'est pas archivé : toute
  modification est enregistrée dans l'historique.

## Répondre à un dossier reçu

Ouvrez le dossier (il passe automatiquement **En cours**), puis dans **Mon traitement** :

- **Envoyer la réponse** (texte + pièces facultatives) ;
- **Transmettre au responsable** si la décision doit être validée : vous répondrez après sa validation ;
- **Transmettre à un autre utilisateur** (commentaire facultatif) ;
- **Archiver mon traitement** une fois la réponse envoyée.

## Notifications

La cloche 🔔 indique le nombre de notifications non lues : nouveau dossier, réponse, document ajouté,
validation, relance, échéance, délai dépassé… Un clic ouvre directement le dossier concerné.

## Retrouver un dossier

Dans **Mes dossiers**, le champ **Rechercher** filtre par référence ou objet, et le filtre **Statut**
par Envoyé, En cours, Répondu ou Archivé. Vous ne voyez que les dossiers auxquels vous avez accès.
